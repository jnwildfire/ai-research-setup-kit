# Overview (step two, not yet made)

This folder will hold one picture of the whole setup, with text beside every graphical part, so that
someone who has never set this up sees at once what is connected to what and what does what.

What it will show:

- **The three roots**: code in git, data on the institution's drive, knowledge in the vault, and the
  one-way flow of data from raw to processed to outputs.
- **The agent and its desk**: what is on it before the first word (the rules file, the skill
  descriptions, the connectors, the memory index) and what piles up during a session.
- **Around the agent**: the rules file, the skills loaded on demand, the hooks that act whatever the
  agent decides, the agents it delegates to, and which model each one runs on.
- **The vault and the products**: notes, cards and decisions in the vault; papers, slides, figures
  and data deliverables made from them.
- **People on one base**: the owner, an assistant, a student, a partner, and the reading flag between
  them.
- **What loads when**: at session start, on a trigger, on a typed command, before every action.

It is drafted as a web page first, iterated with the author, and then placed here as the kit's map.
